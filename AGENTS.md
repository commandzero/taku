## Agent skills

Before contributing, read `docs/repository/contributing.md` for validation and PR requirements. Read `docs/repository/releases.md` when changing versions or distribution. Run `bash scripts/preflight.sh` before completing code changes, or its `docs` mode for documentation-only changes.

### Issue tracker

Issues are tracked in GitHub Issues at `commandzero/taku`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the five default mattpocock/skills label names. See `docs/agents/triage-labels.md`.

### Domain docs

Domain documentation uses a single-context layout. See `docs/agents/domain.md`.
